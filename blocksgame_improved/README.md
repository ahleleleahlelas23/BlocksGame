# Blocks Game - Improved Edition

Улучшенная версия вашей игры Blocks Game!

## Что было улучшено:

### 🎮 Игровой процесс
- **Больший мир**: 30x20 блоков вместо 20x15
- **Улучшенная генерация мира**: с различными слоями, платформами и случайными структурами
- **Новые типы блоков**: 14 типов вместо 9 (камень, дерево, трава, серебро, золото и др.)
- **Непрерывное разрушение/установка**: зажмите ЛКМ/ПКМ для быстрого строительства

### 🎨 Графика
- **Градиенты**: небо и блоки теперь с градиентами для объема
- **Система частиц**: при разрушении блоков вылетают частицы
- **Анимация игрока**: ходьба с анимацией ног, тень под персонажем
- **Плавное выделение**: блок под курсором подсвечивается с анимацией
- **Пульсирующий инвентарь**: выбранный слот красиво пульсирует

### ⚙️ Физика
- **Улучшенное движение**: с ускорением и трением
- **Более плавная гравитация**
- **Исправлены коллизии**: более точное определение столкновений

### 📊 Интерфейс
- **Статистика**: счетчик разрушенных/поставленных блоков и время игры
- **Улучшенное меню**: с кнопкой управления и информацией
- **Диалог управления**: подробное описание всех клавиш

### 🛠️ Технические улучшения
- **Delta time**: игровой цикл использует реальное время между кадрами
- **Ограничение FPS**: защита от проблем при лагах
- **Сглаживание**: включен антиалиасинг для лучшей графики

## Управление:
- **W / Стрелка Вверх / Пробел** - Прыжок
- **A / Стрелка Влево** - Движение влево
- **D / Стрелка Вправо** - Движение вправо
- **ЛКМ (удерживать)** - Разрушить блок
- **ПКМ (удерживать)** - Поставить блок
- **Клавиши 1-9** - Выбор блока из инвентаря
- **ESC** - Выход в меню

## Как запустить:

```bash
java -jar blocksgame_improved.jar
```

## Структура проекта:
```
blocksgame_improved/
├── src/
│   ├── GameEngine.java    - Улучшенный игровой движок
│   ├── BlocksGame.java    - Основная логика игры
│   └── Main.java          - Точка входа и меню
├── out/                   - Скомпилированные классы
└── blocksgame_improved.jar - Готовый JAR файл
```

## Отличия от оригинала:
1. Оригинальный `eng.java` → `GameEngine.java` (улучшенный движок)
2. Оригинальный `BlocksGame.java` → полностью переписан с новыми функциями
3. Оригинальный `Main.java` → улучшенное меню с диалогами
